⚡ QUICK START FOR USERS:

From git clone to running in 5 minutes:

Linux/macOS:
  $ git clone https://github.com/yourusername/bookstore.git
  $ cd sekolah
  $ ./setup.sh

Windows:
  $ git clone https://github.com/yourusername/bookstore.git
  $ cd sekolah
  $ setup.bat

Manual:
  $ cd sekolah
  $ cd backend/bookstore-api && composer install && php artisan serve &
  $ cd frontend/bookstore-web && npm install && npm run dev

Result: App running on http://localhost:3000 ✓
